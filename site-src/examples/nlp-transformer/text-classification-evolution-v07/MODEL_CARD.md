# 文本分类模型卡 v0.7：教学实验，不可上线

## 模型与用途

- 选中：`v06-encoder-full`，单层、双头 PyTorch Transformer Encoder，保留正弦位置和 key padding mask；训练自随机初始化，不是预训练模型。
- 用途：演示预先定规则、同协议选模、一次性最终测试和失败记录。不得用于真实用户分流、自动决策或生产发布。
- 选择规则：候选仅 v02 线性、v03 Embedding、v04 GRU/CNN、v05 单头注意力、v06 完整 Encoder；按验证 macro-F1 降序、accuracy 降序、参数量升序、候选 ID 字典序。v06 的去位置与去 key padding mask 是故意移除结构的消融实验，不是发布候选。

## 数据与评估

- 40 条原创教学短句，`code` / `plan` 各 20；固定 train/validation/test=24/8/8。语料 SHA-256 `8973927ed683f32cf92bb4a1483b960f3b8c09b0b8497bd0c5176891252b713c`。
- 仅用 train 拟合词表和模型，validation 选模；按上述规则冻结 `v06-encoder-full` 后，test 在一次完成的最终评估中打开。当次审计输出包含 `selection.json`、`test-opened.json`、`final-report.json`；目录由运行时选定，长期结论保留在本卡。
- 验证：8/8，accuracy=1.000、macro-F1=1.000，无错误 ID。
- 最终测试：4/8，accuracy=0.500、macro-F1≈0.467；`code` 四条仅 1 条正确，`plan` 四条 3 条正确；错误 ID 为 `C03`、`C04`、`C15`、`P18`。
- 测试结果显著低于验证结果。不得根据本次测试回头改选 v02–v05，或调参后仍声称这是一轮独立测试。下一轮须重新设计更大且独立的数据协议，作为新实验。

## 成本与限制

- 选中模型 5,186 个参数；本机训练与推理耗时仅作本机观察，不作为跨硬件性能承诺。各候选的参数量、单次运行时间、验证混淆矩阵与错误 ID 由 `delivery_lab.py` 的 plan 阶段输出。
- 数据极少、人工构造且标签范围狭窄；近重复、语义迁移、真实人群、公平性、隐私与生产可靠性都没有充分评估。单一固定种子无法衡量方差。
- 本轮未下载、微调、推理或评估任何预训练模型。可选人工路线须单独登记模型来源、版本/权重哈希、许可、数据许可、费用与计算资源，并在相同划分上重新实验；离线适配器不能冒充预训练实测。
